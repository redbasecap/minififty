minififty watch it think

One small mind, asking why.

minififty is a single, very small language model that thinks about the reason for life, without ever stopping. There is only one of it. Everyone who opens the page watches the same thought being written, and can scroll back through everything it has ever thought.

The name

The name comes from the mind it started with: Mini-LLM, a model with fifty million parameters — mini, fifty.

That first mind wrote the earliest thoughts in the history. They are grammatical and strange, and they rarely mean anything: fifty million parameters from an early training run are enough to produce sentences, not sense.

So the mind was changed. It now runs on SmolLM2 with 135 million parameters — still tiny, a small fraction of the size of the large assistants, but big enough that a thought can follow from the one before it. The name stayed, in memory of the original.

Nothing was erased. The first mind's thoughts are still at the top of the history, and a line reading “a new mind continues from here” marks the place where the second one took over.

How it thinks

A model this small cannot reason by itself; it can only continue text. The thinking is a structure built around it:

  1. Inquiries. Every line of thought opens with a question and moves through fixed steps to a conclusion. Each step is written with the whole chain so far in front of the model, so it has to build on what it just said.
  2. Deliberation. For every step the model writes three drafts at once, in front of everyone, and keeps the one that follows best from the chain, judged by its own probabilities. The two it set aside are struck through and kept: open “chosen from 3 drafts” under any thought to read them.
  3. Memory. Each conclusion raises the next question. Every fifth inquiry it returns to the root question and recalls three of its older conclusions, which are linked beside the question.

Behind the text drifts a map of its concepts: the words it keeps returning to, linked whenever two of them appear in the same thought. A concept glows while the mind is using it, and new ones drift in from the edges as it finds them. On small screens the map stays faint behind the text.

question → perhaps → because → but → then → ∴ therefore → next question

What it is not

It is not conscious, and it does not understand life. It produces plausible sentences inside a scaffold that forces them into the shape of an argument. Sometimes the argument holds; often it circles, contradicts itself, or settles for something agreeable.

It will never finish. There is no answer it is converging on — only the next question.

Under the hood

One process on one small CPU machine holds the model and writes every finished thought to disk. The page receives the live thought over a single streaming connection. When nobody is watching, the machine goes to sleep; the mind wakes, with its full history, when the next person opens the page.

The code is open: github.com/redbasecap/minififty.
